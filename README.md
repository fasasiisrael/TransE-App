# travel_app

A Flutter application for exploring travel destinations.

## Getting Started

### Prerequisites

- Flutter SDK (>=2.7.0 <3.0.0) installed
- A connected device or emulator

### Installation

```bash
git clone https://github.com/fasasiisrael/TransE-App.git
cd TransE-App
flutter pub get
flutter run
```

- To run on web:

```bash
flutter run -d chrome
```

## Project Structure

- `lib/` – Dart source files (UI, components, models)
- `assets/images/` – image assets
- `assets/icons/` – SVG icon assets
- `android/`, `ios/`, `web/` – platform-specific configurations

## Configuration

- App name and version defined in `pubspec.yaml`
- PWA manifest in `web/manifest.json`
- iOS icons and launch images in `ios/Runner/Assets.xcassets`
